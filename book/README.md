# Making Meaning: Persuasion, Brand, and Design

This mini textbook explores how ordinary products become meaningful through communication. It follows one plain white T-shirt across five chapters to show how persuasion, brand archetypes, and visual language shape what an audience notices, feels, trusts, and does.

## How to Use This Guide

Read the chapters in order the first time. Chapter 1 introduces how communication influences decisions. Chapter 2 adds identity and narrative patterns. Chapter 3 shows how visual systems and stylistic choices carry meaning. Chapter 4 combines all three lenses in one case study. Chapter 5 turns the ideas into a practical method for directing and reviewing AI-assisted work.

As you read, pause at the questions and test each idea against a product, organization, or interface you already know. Notice what changes when the audience, archetype, persuasive goal, or visual language changes. The guide is a starting point for your judgment, not a substitute for it.
