# Designing Meaning

## A Mini Textbook About Persuasion, Brands, and Visual Language

Design does more than decorate information. It shapes attention, gives products and organizations recognizable meaning, and helps audiences decide what to trust or do. This short guide moves from persuasion and archetypes through design history and a plain white T-shirt case study, then connects those ideas to AI-assisted work.

## How to Use This Guide

Read the chapters in order the first time: each one adds a lens to the next. As you read, keep returning to the same question: **What is this design helping someone feel, understand, or choose?** Use the examples as starting points, then test the ideas against designs you encounter in daily life.
