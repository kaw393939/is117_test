# Designing with AI: Persuasion, Archetypes, and Visual Language

This mini textbook is a practical guide to designing thoughtful, intentional work with AI. It brings together three lenses that help shape creative and technical decisions: persuasion, meaning, and visual language. Each chapter builds toward a clearer understanding of how humans can guide AI without surrendering judgment, responsibility, or context.

## How to Use This Guide

Read the chapters in order. Each section adds another layer to the same core idea: creative work becomes more effective when purpose, identity, and visual expression are made explicit.

Use the guide as a working reference when you are:

- designing a project brief;
- writing prompts for AI-assisted work;
- deciding what a brand should communicate;
- evaluating drafts for clarity, consistency, and trust;
- reviewing outputs before publication or submission.

The chapters are meant to be practical. You do not need to read them as abstract theory alone. Treat them as a framework you can return to whenever a project needs better direction, clearer communication, or stronger human judgment.
