+# IS 117 Practical Specification

## Objective

Create a small Markdown-based learning guide by completing five bounded AI-assisted work items using a professional Git workflow.

## Required Repository Artifacts

By the end of the practical, the repository must contain:

- `book/01-persuasion.md`
- `book/02-archetypes.md`
- `book/03-design-language.md`
- `book/04-white-tshirt-case-study.md`
- `book/05-synthesis.md`
- `book/README.md`

## Required Process

Each stage should be completed through a separate GitHub issue and branch.

Students should:

1. create the issue
2. create a branch
3. execute the supplied prompt
4. review AI output
5. commit the result
6. reference the issue number in the commit
7. push
8. merge
9. verify the repository

## Design Principles

The practical models:

- bounded AI tasks
- spec-driven work
- traceability
- deterministic verification
- human review
- recoverability through version control

## Content Goal

The finished guide should help a first-year student understand how these three lenses can work together:

### Persuasion
How people make decisions and how communication can influence attention, trust, and action.

### Brand Archetypes
How brands attach meaning, identity, and narrative to otherwise ordinary products.

### Design Language
How visual traditions such as modernism and postmodernism create different expectations, moods, and meanings.

The guide should use a recurring case study:

> How could the same plain white T-shirt be presented as different products by changing persuasion, archetype, and design language?

## Human-in-the-Loop Principle

Automation should handle fast, repeatable checks.

AI may assist with interpretation and generation.

Humans remain responsible for:

- intent
- judgment
- truthfulness
- appropriateness
- quality
- meaning
- final editorial decisions
